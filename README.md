# LightCrush 🗜️

LightCrush is an ultra-lightweight, blazing-fast, entirely offline image compressor and converter. 

Built with React, Vite, and Neutralinojs, it provides a seamless and visually stunning UI while running natively on Windows, macOS, and Linux without the massive overhead of Electron.

## Features
- **Zero Cloud Uploads**: All image compression is handled 100% locally on your machine.
- **Ultra-Lightweight**: The entire standalone executable is under 2 MB.
- **Cross Platform**: Runs flawlessly on Windows, macOS, and Linux.
- **Multi-Format Support**: Compress and convert between JPG, PNG, and WebP.
- **Before/After Previews**: Interactively slide to compare the original and compressed images.

## Development

```bash
# Install dependencies
npm install

# Run web app locally
npm run dev

# Build the web app
npm run build

# Build standalone desktop executables for all OS
npm run build:desktop
```
