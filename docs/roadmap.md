# Roadmap

## Near Term

- Add generated preview thumbnails instead of full image previews.
- Add fixture-based backend tests for metadata and output format selection.
- Improve PNG optimization controls.
- Add better Windows packaging polish.
- Add portable Windows build instructions.

## Planned Features

- Folder watcher
- Right-click Windows context menu
- PDF image extraction
- More advanced AVIF support
- Lossless PNG optimization
- Image quality score
- Duplicate image finder

## Non-Goals

- Cloud upload
- Analytics
- Telemetry
- Login
- Ads
- Required VPS or backend service
